# Tiny test fixture

`tiny.bam` and `tiny.bam.bai` are deterministic, committed fixtures generated by `tests/make_tiny_fixture.cpp` using the same helper (`tests::make_bam`) that the test suite uses.

Regenerate from the repository root:

```bash
cmake --build build --target covidx_make_fixture
./build/covidx_make_fixture tests/data
```

Contents:

- `chr1` length 1000 with reads covering `M/I/D/N/S/H/P/=/X`, ambiguous bases, duplicate/secondary/QC-fail/supplementary alignments, a low-MAPQ read, a `SEQ=*` read, and reads at the start/end.
- `chr2` length 500 with no reads.
- Five read groups over four samples (`S1`, `S2`, `S3`, `S4`); `S2` has two read groups and `S3` has none.

`tiny_scope.bed` contains overlapping and touching `--regions` intervals. `golden_index.sha256` lists the SHA-256 hashes of the committed golden index built with `SOURCE_DATE_EPOCH=0` and one thread. The golden index uses format `1.1.0` and includes feature-count segments.

Do not edit the BAM or BAI by hand. Regenerate both together.
